# Zip Auto Switcher — оновлення

Версія **1.7.0 — тестова** (12.11.2026): список програм із галочками перенесено в «Налаштування → Програми», звуки відокремлено від функцій друку, додано підказки з прикладами. Профілі Gemini, OpenAI, Claude, Groq, OpenRouter та сумісних API мають незалежні зашифровані ключі й моделі. **Ctrl+Alt+F8** перемикає лише підключені ввімкнені сервіси. Список дозволів обмежує автоматичні виправлення; ручний ШІ доступний незалежно від нього, крім полів пароля. Виправлено затримку перевірки стандартних редакторів, продовження слова після паузи й перевірку виділення ШІ. Додано обережну обробку подвійних близьких натискань. Старі ключі й локальні налаштування зберігаються. Google перевірено живими запитами в обох мовах; інші формати API — офлайн, без платних запитів.

Версія **1.6.9 — тестова** (11.11.2026): захист коротких українських слів, консервативне виправлення близьких зайвих натискань, розширений захист назв. Повне збирання відповіді ШІ, звіряння виділення у підтримуваних редакторах і центровані сповіщення. **Після оновлення дозвольте потрібні програми в новому запиті; змінити рішення можна через «Дозволені програми…» у треї.** Діалоги файлів, Explorer, паролі та адресний рядок браузера виключені. Недоступні для перевірки поля пропускаються. Дозволи зберігаються локально в `applications.ini` і не публікуються. Автоматичні та інтерактивні тести цієї збірки не запускалися.

Версія **1.6.8 — тестова** (04.11.2026): включає оновлення 1.6.7 і словникове відновлення апострофа під час друку. Приклади: `зїднай` → `з'єднай`, `зєднай` → `з'єднай`. Виправлення виконується після пробілу, Enter чи розділового знака. Автоматичні тести цієї збірки не запускалися.

Версія **1.6.7** (03.11.2026): актуальні виправлення 1.6.6, захист стандартних полів пароля від автоматичної та ручної заміни. У вихідному репозиторії додано автономний набір перевірок без токенів: випадкові дані, повторні прогони та звіти для подальшого аналізу ШІ. Обмеження строку використання немає.

Попередні офлайн-перевірки: два цикли, 28 виконаних перевірок без збоїв, 120 000 випадкових прикладів і 374 перевірки живого вводу. Встановлення/відкат у цьому прогоні явно пропущено через призупинення тимчасових тестових процесів у середовищі агента. Ранній нестабільний випадок швидкого вводу не відтворився у фінальних циклах; це не є гарантією відсутності всіх помилок.

Офіційні готові випуски Zip Auto Switcher для Windows.

[Завантажити портативний архів](https://raw.githubusercontent.com/zipkiev/ZipAutoSwitcher-updates/main/ZipAutoSwitcher_latest.zip)

Версія **1.6.6 — тестова** (03.11.2026): прибрано помилкове перетворення українських слів на латинські набори символів за групою приголосних; додано захист форм прикметників, зокрема `верхньої`. Обмеження строку використання немає. Виправлення працює локально, без передавання набраного тексту. Автоматичні тести цієї збірки не запускалися; триває ручне тестування.

Для першого запуску розпакуйте архів і запустіть `ZipAutoSwitcher/ZipAutoSwitcher.exe`. Для ручного оновлення спочатку закрийте програму, розпакуйте новий архів в окрему папку й замініть лише `ZipAutoSwitcher.exe` у вашій робочій папці. Збережіть свій `config.ini` і дані доступу. Починаючи з 1.6.3, команда «Перевірити оновлення…» в меню трея перевіряє контрольну суму, встановлює EXE та перезапускає програму. Старішим версіям потрібне одноразове ручне оновлення до 1.6.3.

`version.json` містить версію, розмір і SHA-256 виконуваного файлу.

У цьому сховищі немає вихідного коду, особистих API-ключів, налаштувань користувачів, стану доступу чи генератора кодів. Приватні дані не потрібні для завантаження оновлень.
